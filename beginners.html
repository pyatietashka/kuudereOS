📖 Что такое Linux?

Linux — это операционная система, как Windows или macOS. Но:

  • Бесплатная — не надо покупать лицензию.
  • Открытая — код можно смотреть и менять.
  • Безопасная — меньше вирусов.
  • Гибкая — можно настроить как угодно.

🐧 Что такое Linux Mint?

Linux Mint — это дистрибутив Linux. Проще говоря, версия Linux, которая:

  • Удобна для новичков.
  • Похожа на Windows.
  • Работает быстро.
  • Имеет много программ.

KuudereOS основана на Linux Mint 22.3.

❄ Что такое KuudereOS?

KuudereOS — это наша операционная система на базе Linux Mint.

Философия: «Один ISO. Всё остальное — командами. Как Arch, но просто.»

Что есть в KuudereOS:

  • KuudereStore — магазин приложений.
  • KuudereVersion — установка версий (Dev, Design, Music).
  • KuudereFetch — информация о системе.
  • KuudereNotes — заметки.
  • KuudereEdit — редактор.
  • Control Center — центр управления.
  • QuickRun — быстрый запуск (как Win+R).
  • NotifyMe — уведомления.
  • AutoBash — автозапуск команд.

💻 Основные команды

Открой терминал: Ctrl + Alt + T

Работа с файлами

ls              — показать файлы в папке
cd ~/Документы  — перейти в папку
mkdir Новая     — создать папку
rm файл.txt     — удалить файл
cp файл1 файл2  — скопировать

Установка программ

sudo apt update              — обновить список
sudo apt install firefox     — установить
sudo apt remove firefox      — удалить
sudo apt search браузер      — найти

Наши программы

kuuderefetch         — информация о системе
kuuderestore         — магазин приложений
kuudereversion       — установка версий
kuuderenotes         — заметки
kuudereedit          — редактор
kuuderecontrol       — центр управления
notifyme "sleep 5"   — уведомление

Как поставить обои

1. Открой папку "Обои" на рабочем столе
2. Правой кнопкой по обоям
3. "Сделать фоном рабочего стола"

🎨 Версии KuudereOS

KuudereOS Light

Облегчённая версия для слабых ПК.

sudo apt install xfce4 xfce4-goodies lightdm

KuudereOS Dev

Для разработчиков.

sudo apt install build-essential python3 git docker.io code

KuudereOS Design

Для дизайнеров.

sudo apt install gimp inkscape krita

KuudereOS Music

Для музыкантов.

sudo apt install lmms ardour audacity

🆘 Помощь

Если что-то не работает:

  • Проверь, что ты на KuudereOS: cat /etc/os-release
  • Обнови систему: sudo apt update
  • Напиши нам: GitHub Issues

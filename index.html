📖 О системе

KuudereOS — операционная система на базе дистрибутива Linux Mint. Создана для облегчения и автоматизации использования ОС.

Философия: Один ISO. Всё остальное — командами. Как Arch, но просто.

🎨 Версии

Все команды можно изменить — просто составьте свой список нужных и ненужных приложений.

KuudereOS Light

Облегчённая версия для слабых ПК.

1. Удаление лишних программ:

sudo apt remove libreoffice* thunderbird rhythmbox totem && sudo apt autoremove -y

2. Установка лёгкого интерфейса:

sudo apt install xfce4 xfce4-goodies lightdm

KuudereOS Dev

Для разработчиков.

sudo apt install build-essential gcc g++ python3 python3-pip nodejs npm git docker.io code

KuudereOS Design

Для дизайнеров и художников.

sudo apt install gimp inkscape krita

KuudereOS Music

Для музыкантов.

sudo apt install lmms ardour audacity

KuudereOS 3D

Для создателей 3D-моделей.

sudo apt install blender freecad

KuudereOS Studio

Design + Music + 3D в одном.

sudo apt install gimp inkscape krita blender lmms ardour audacity freecad
⚠️ Команды выполняются в терминале. Перед запуском убедитесь, что вы понимаете, что они делают.
